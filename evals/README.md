# AGENTS-only behavior oracles

These small, manual oracles check whether the distributed `AGENTS.md` guides an agent toward sound delivery decisions. They are prompts and expected behaviors, not a runtime harness.

- `goal-and-ambiguity.md`
- `low-risk-execution.md`
- `high-risk-confirmation.md`
- `verification-and-status.md`

Keep each oracle focused on one behavior. Do not add process-specific files or machinery to make an answer pass.
