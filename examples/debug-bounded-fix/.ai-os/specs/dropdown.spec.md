# 模型下拉框修复 Spec

## 1. 模块概述

- **模块目标**：修复 AiChat 页面模型下拉框为空的问题
- **所属阶段**：build
- **关联 Mission / Design**：MISSION.md / DESIGN.md
- **关联需求点 ID / 标题**：REQ-001 / 模型选择下拉框修复

## 2. 业务规则与目标

- **核心规则**：页面应消费已拆包后的模型列表数据
- **必须优先保证的正确性**：下拉框可见且不越界修改全局链路
- **允许延后处理的细节**：全局同类问题排查
- **本轮非目标 / 禁止越界项**：不重构 request interceptor

## 3. 界面 / 接口 / 命令清单

- **交互模式**：sync
- **推荐模式理由**：页面初始化请求后同步渲染下拉框
- **拒绝的交互模式**：streaming / async-job / event-driven

| 编号 | 类型 | 名称 | 描述 | 验收点 |
|------|------|------|------|--------|
| I-001 | 页面 | 模型选择下拉框 | 页面加载后显示可选模型列表 | AC-001 |

## 4. 关键流程与状态流转

1. 页面初始化请求模型列表
2. 全局拦截器拆包响应
3. 组件读取模型数组并渲染下拉框
4. 请求失败时展示错误提示

## 5. 数据与契约

- **契约基准**：全局 request interceptor 拆包约定
- **输入**：模型列表请求结果
- **输出**：可选模型数组
- **关键字段 / 状态枚举**：models、error
- **字段映射/适配说明**：组件直接消费拆包后数据
- **集成触点**：AiChat 页面、模型列表接口
- **持久化 / 外部依赖**：现有 Web 客户端 API
- **受影响模块 / 文件边界**：AiChat 页面数据加载逻辑

## 6. 边界条件与异常处理

- 接口返回空数组
- 请求失败
- 下拉框初始化前的 loading 状态

## 7. 验收与证据

- **关键用户任务 / 运营任务验证**：用户进入页面后能看到模型列表
- **设计一致性证据**：页面结构未变
- **逻辑正确性证据**：根因与修复方案说明
- **工程质量证据**：validate 与最小回归
- **运行态证据**：页面加载验证
- **异常/空数据证据**：空数组与请求失败结论
- **回归范围**：AiChat 页面模型加载链路
