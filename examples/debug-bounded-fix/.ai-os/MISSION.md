# Mission

## 1. 任务定义

- **项目名称**：AiChat 下拉框为空修复
- **一句话目标**：修复 AiChat 页面模型选择下拉框数据为空的问题
- **当前治理档位**：standard（P2 级单点修复）

## 2. 用户与场景

- 用户进入 AiChat 页面，模型选择下拉框为空

## 3. 项目模式、质量目标与关键选型

- **模式**：brownfield / debug
- **质量目标**：修复下拉框显示，不引入回归

## 4. 范围边界

| 范围内 | 范围外 |
|--------|--------|
| 修复下拉框数据加载 | 其他页面功能 |
| 验证回归 | UI 样式调整 |

## 5. 阶段计划

- 定位根因 → 确认方案 → 修复 → 回归验证

## 6. 已知输入与待确认项

- 已确认根因：全局 request 拦截器已做响应拆包，但组件仍按 `res.code === 200` 判断
- 待确认：是否还有其他组件存在同类问题

## 7. 风险与外部依赖

- 需确认全局拦截器影响范围
