# 代码约定

## 命名约定

- **函数命名模式**：语义化 camelCase
- **变量 / 常量命名**：变量 camelCase，常量 UPPER_SNAKE_CASE
- **文件 / 目录命名**：与页面或组件语义保持一致

## 代码模式

- **数据获取**：沿用全局 request 拦截器约定
- **错误处理**：页面显示可读错误，不重复拆包
- **状态管理**：局部状态仅在页面组件内部维护

## 导入与分层

- **允许的导入方向**：页面 -> 服务 / API
- **禁止的跨层依赖**：页面不重复实现拦截器职责

## 日志约定

- **日志框架**：沿用现有前端日志方式
- **日志级别使用**：请求异常保留错误上下文
- **必须包含的上下文**：页面入口、请求结果、空数据原因

## 禁止模式

- 不在页面里再次判断全局已拆包的 `res.code`
- 不把单点修复扩展成无边界重构
