# 代码约定

## 命名约定

- **函数命名模式**：动词开头 camelCase
- **变量 / 常量命名**：变量 camelCase，常量 UPPER_SNAKE_CASE
- **文件 / 目录命名**：按模块语义拆分

## 代码模式

- **数据获取**：沿用现有 API 包装层
- **错误处理**：限制校验失败必须走统一提示
- **状态管理**：局部状态只在相关模块内维护

## 导入与分层

- **允许的导入方向**：页面 / 入口 -> 服务 -> 适配层
- **禁止的跨层依赖**：局部变更不得绕开共享基础设施直接写补丁

## 日志约定

- **日志框架**：沿用宿主项目默认方案
- **日志级别使用**：限制命中至少留业务日志
- **必须包含的上下文**：用户操作、限制规则、影响入口

## 禁止模式

- 不把局部修复扩散成全局重构
- 不绕开共享 request / adapter 约定
