# Mission

## 1. 交付基线摘要

- **宿主项目 / 系统**：权益账户服务
- **当前交付主题**：权益扣减与状态流转重构
- **当前交付目标**：重构资产扣减接口，确保并发安全、审计可追溯、状态流转不可逆
- **成功标准**：zero data loss、audit trail、idempotent
- **项目模式**：brownfield
- **当前交付档位**：high-risk
- **当前治理档位**：P0
- **当前基线 ID**：BL-20260321-153000-state-transition-rebuild

## 2. 用户与闭环场景

- **目标用户**：后台运营人员与账户系统用户
- **关键场景**：后台触发批量扣减，用户端实时看到余额变化
- **目标市场 / 使用环境**：现有权益账户系统
- **当前最小可行闭环**：一次扣减请求可安全落账并留审计痕迹
- **明确后续迭代项**：报表与可视化运营面板

## 3. 已确认约束与关键决策

- **已确认技术栈与关键选型**：沿用现有账户服务、数据库事务和审计日志体系
- **已确认目标运行态 / 部署约束**：需要兼容现有数据库迁移窗口
- **已确认质量优先级**：资产安全 > 并发正确 > 审计可追溯 > 交付速度
- **必须保持的宿主项目约束**：扣减链路必须保持幂等和审计可回放
- **已确认核心设计决策**：扣减与状态流转在同一高风险交付内治理
- **已确认核心逻辑决策**：状态流转不可逆，失败需明确补偿策略

### 已确认非功能性约束
- 必须满足并发安全和审计可追溯要求

## 4. 范围边界与非目标

### 范围内
- 扣减接口重构
- 并发控制
- 审计日志

### 范围外
- 充值流程
- 前端 UI
- 报表系统

### 非目标
- 不同时重做非扣减路径的账户模型

|---------|--------|------|----------|

## 5. 稳定风险与外部依赖

- **外部依赖**：中台账户服务、数据库迁移窗口
- **稳定风险**：高并发下的幂等性、补偿与审计一致性
- **高风险触发因素**：资产扣减、不可逆状态流转、并发敏感
- **影响范围摘要**：权益账户扣减与审计链路
- **审批点**：扣减失败重试策略、审计日志保留周期
