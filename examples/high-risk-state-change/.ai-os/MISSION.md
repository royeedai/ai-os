# Mission

## 1. 任务定义

- **项目名称**：权益扣减与状态流转重构
- **一句话目标**：重构资产扣减接口，确保并发安全、审计可追溯、状态流转不可逆
- **当前治理档位**：high-risk

## 2. 用户与场景

- 运营人员通过后台触发批量扣减
- 用户端实时查看余额变化

## 3. 项目模式、质量目标与关键选型

- **模式**：brownfield
- **质量目标**：zero data loss, audit trail, idempotent
- **高风险触发因素**：资产扣减、不可逆状态流转、并发敏感

## 4. 范围边界

| 范围内 | 范围外 |
|--------|--------|
| 扣减接口重构 | 充值流程 |
| 并发控制 | 前端 UI |
| 审计日志 | 报表系统 |

## 5. 阶段计划

- Phase 1: 锁定接口契约和并发策略
- Phase 2: 实现和验证

## 6. 已知输入与待确认项

- 待确认：扣减失败重试策略
- 待确认：审计日志保留周期

## 7. 风险与外部依赖

- 依赖中台账户服务
- 依赖数据库迁移窗口
