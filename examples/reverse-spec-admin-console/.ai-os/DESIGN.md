# Demo Design

## 1. 设计目标

- **本轮设计目标**：锁定后台首页、列表页和编辑流程
- **需要先锁定的关键页面 / 交互**：列表、详情、编辑
- **允许后补的细节**：空态文案

## 2. 信息架构

- **入口与导航骨架**：工作台 -> 列表 -> 详情 / 编辑
- **一级 / 二级结构**：一级菜单 + 二级页面
- **关键上下文切换点**：组织切换

## 3. 关键页面与交互

| 页面 / 入口 | 目标 | 关键元素 | 关键操作 | 确认状态 |
|-------------|------|----------|----------|----------|
| 列表页 | 浏览和筛选数据 | 搜索区、表格、操作列 | 筛选、详情、编辑 | confirmed |

## 4. 关键流程

1. 进入列表页
2. 筛选并进入详情
3. 编辑后返回列表

## 5. 视觉方向

- **视觉参考**：国内企业后台
- **信息密度 / 布局原则**：中高密度
- **组件与交互风格**：列表区与编辑流程分离
- **明确不采用的风格**：列表和完整表单粗暴同屏

## 7. 差异与待确认项

- **相对参考对象的明确差异**：文案本地化
- **仍待确认的设计项**：详情页布局
