# Mission

## 1. 交付基线摘要

- **宿主项目 / 系统**：todo-cli
- **当前交付主题**：报表导出 lane
- **当前交付目标**：为 todo-cli 增加 `export` 命令，生成 JSONL / CSV 快照
- **成功标准**：导出命令可用、过滤语义与 list 保持一致、导出过程不修改原始数据
- **项目模式**：change
- **当前交付档位**：standard
- **当前治理档位**：P1
- **当前基线 ID**：BL-20260316-091500-reporting-export

## 2. 用户与闭环场景

- **目标用户**：需要把待办导出为日报或对账材料的开发者
- **关键场景**：在终端执行 `todo export` 生成可共享的快照文件
- **目标市场 / 使用环境**：本地命令行
- **当前最小可行闭环**：支持 `jsonl` / `csv` 导出和 `--all|--done|--pending` 过滤
- **明确后续迭代项**：计划任务、压缩包和远端上传

## 3. 已确认约束与关键决策

- **已确认技术栈与关键选型**：Node.js、JSON 文件存储、无外部依赖
- **已确认目标运行态 / 部署约束**：本地文件存储，导出路径由命令参数给出
- **已确认质量优先级**：不破坏现有 CLI 契约 > 导出正确 > 交付速度
- **必须保持的宿主项目约束**：继续复用 `src/store.js`，不得改写主线 list 输出格式
- **已确认核心设计决策**：新增 `todo export --format <jsonl|csv> --output <path>`
- **已确认核心逻辑决策**：过滤语义与 `list` 保持一致；导出过程只读，不修改原始数据

### 已确认非功能性约束
- 不引入第三方 CSV 库

## 4. 范围边界与非目标

### 范围内
- `export` 子命令
- `jsonl` / `csv` 格式输出
- 过滤选项与最小 smoke 验证

### 范围外
- 云同步
- 定时导出
- 压缩包与邮件发送

### 非目标
- 不改变现有 CRUD 命令输出格式

|---------|--------|------|----------|

## 5. 稳定风险与外部依赖

- **外部依赖**：无
- **稳定风险**：共享 store 契约被误改、CSV 转义遗漏、导出命令误修改原始数据
- **高风险触发因素**：共享入口命令新增子命令，可能影响现有 CLI help 和解析
- **影响范围摘要**：`bin/todo.js`、`src/commands.js`、导出模块
- **审批点**：无
