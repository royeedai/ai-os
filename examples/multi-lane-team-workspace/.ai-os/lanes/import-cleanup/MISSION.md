# Mission

## 1. 交付基线摘要

- **宿主项目 / 系统**：todo-cli
- **当前交付主题**：导入清洗 lane
- **当前交付目标**：为 todo-cli 增加导入前清洗流程，统一处理 BOM、空行和重复文本
- **成功标准**：导入命令可用、清洗规则稳定、不会写入脏数据
- **项目模式**：change
- **当前交付档位**：standard
- **当前治理档位**：P1
- **当前基线 ID**：BL-20260315-164500-import-cleanup

## 2. 用户与闭环场景

- **目标用户**：需要批量导入待办的开发者
- **关键场景**：从文件或粘贴文本导入 todo 列表
- **目标市场 / 使用环境**：本地命令行
- **当前最小可行闭环**：在导入前完成 BOM 清理、空行过滤和重复文本去重
- **明确后续迭代项**：导入预览、冲突提示

## 3. 已确认约束与关键决策

- **已确认技术栈与关键选型**：Node.js、JSON 文件存储、无外部依赖
- **已确认目标运行态 / 部署约束**：本地文件导入，仍写入 `~/.todo.json`
- **已确认质量优先级**：数据正确 > 导入体验 > 交付速度
- **必须保持的宿主项目约束**：导入后仍写入共享 store 契约 `{ id, text, done, createdAt }`
- **已确认核心设计决策**：导入链路拆成 parse -> normalize -> persist
- **已确认核心逻辑决策**：先 trim / 去 BOM / 去空行 / 去重，再分配新 ID

### 已确认非功能性约束
- 不引入第三方 CSV / parser 依赖

## 4. 范围边界与非目标

### 范围内
- 导入前清洗规则
- 导入 smoke
- 稳定结论回流到共享 memory / CONVENTIONS

### 范围外
- 导入预览 UI
- 自动冲突合并策略
- 云端同步

### 非目标
- 不改变既有 CRUD 和导出命令语义

## 5. 稳定风险与外部依赖

- **外部依赖**：无
- **稳定风险**：导入脏数据污染共享 store、导入逻辑绕开 normalize 阶段
- **高风险触发因素**：共享存储契约被误写、ID 分配错误
- **影响范围摘要**：导入模块、shared memory、shared conventions
- **审批点**：无
