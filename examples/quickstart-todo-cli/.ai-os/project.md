# 项目章程

> 本文件记录 todo-cli 宿主项目的共享事实，不属于单条交付线。
> 当前示例采用 `lanes/default` 作为唯一活跃 lane，交付工件位于 `.ai-os/lanes/default/`。

## 项目身份

- **项目名称**：todo-cli
- **项目类型**：CLI 工具
- **仓库地址**：示例仓库（无远端）
- **主要语言与框架**：Node.js，无外部依赖

## 共享技术约束

- **运行态 / 部署环境**：本地命令行
- **核心依赖与版本锁定**：Node.js LTS，JSON 文件读写
- **API / 数据协议约束**：Todo 数据持久化为本地 JSON 数组
- **安全与合规要求**：仅本地单用户使用，不处理敏感云端数据

## 共享质量基线

- **代码规范**：参见 `CONVENTIONS.md`
- **测试策略**：以命令级回归和关键异常路径验证为主
- **CI / CD 管道**：示例未接入远程 CI
- **发布节奏**：以本地 CLI 可运行交付为准

## 团队与协作

- **项目负责人**：AI-OS quickstart 示例
- **活跃交付线**：`default`
- **跨 lane 协调规则**：当前示例只维护一个默认 lane
