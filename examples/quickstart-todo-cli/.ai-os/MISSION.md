# Mission

## 1. 任务定义

- **项目名称**：todo-cli
- **一句话目标**：用 Node.js 构建一个本地文件存储的命令行 Todo 管理工具
- **当前治理档位**：standard

## 2. 用户与场景

- 开发者在终端管理日常任务
- 支持增删改查和状态标记

## 3. 项目模式、质量目标与关键选型

- **模式**：greenfield
- **质量目标**：命令可用、数据不丢、错误有提示
- **关键选型**：Node.js、JSON 文件存储、无外部依赖
- **高风险触发因素**：无

## 4. 范围边界

| 范围内 | 范围外 |
|--------|--------|
| add / list / done / delete 命令 | 云同步 |
| JSON 文件持久化 | 多用户 |
| 基本错误处理 | GUI 界面 |

## 5. 阶段计划

- Phase 1: 核心 CRUD 命令
- Phase 2: 状态过滤和格式化输出

## 6. 已知输入与待确认项

- 已确认：使用 ~/.todo.json 作为存储路径
- 已确认：todo ID 使用自增整数

## 7. 风险与外部依赖

- 无外部依赖
- 文件并发写入风险低（单用户）
