# Examples

Canonical AI-OS v8 project scenarios. Each example is a **narrative walkthrough** showing how the constitution + 12 artifacts handle a specific project shape. The real canonical example is your own repository after running `create-ai-os .` — these narratives just show what to expect.

| File | Scenario |
|---|---|
| [greenfield-guided-product.md](greenfield-guided-product.md) | Brand new product from an idea |
| [brownfield-change-journey.md](brownfield-change-journey.md) | Adding a feature to an existing codebase |
| [debug-bounded-fix.md](debug-bounded-fix.md) | Bounded bug fix without over-scope |
| [high-risk-state-change.md](high-risk-state-change.md) | Irreversible state / permission change with explicit approval gates |
| [coexist-with-spec-kit.md](coexist-with-spec-kit.md) | Running Spec-Kit (0→1) + AI-OS (lifecycle) together |

See [../docs/getting-started.md](../docs/getting-started.md) to run any of these in your own repo.
