# Examples

Canonical AI-OS project scenarios. Each example is a **narrative walkthrough** showing how the constitution + canonical lane-first artifacts handle a specific project shape. The real canonical example is your own repository after running `create-ai-os .` — these narratives just show what to expect.

| File | Scenario |
|---|---|
| [greenfield-guided-product.md](greenfield-guided-product.md) | Brand new product from an idea |
| [brownfield-change-journey.md](brownfield-change-journey.md) | Adding a feature to an existing codebase |
| [debug-bounded-fix.md](debug-bounded-fix.md) | Bounded bug fix without over-scope |

See [../docs/getting-started.md](../docs/getting-started.md) to run any of these in your own repo.
