# CLI（vNext）

## 常用命令

```bash
create-ai-os .
create-ai-os doctor .
create-ai-os validate .
create-ai-os status .
create-ai-os next .
create-ai-os resume .
create-ai-os migrate .
create-ai-os release-check .
```

## 最重要的 4 个命令

- `doctor`：看框架和核心工件是否齐
- `validate`：看 Mission / Design / Spec / Tasks / Acceptance / State 是否完整
- `resume`：导出最小阅读集
- `migrate`：把旧版工件映射到 vNext
