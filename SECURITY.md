# Security Policy

## Supported versions

The current supported public release is `v10.5.1`. The `main` branch is unreleased;
the `11.0.0` source tree remains development work until the complete release
gate has passed and a public tag exists.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Include the
affected ref, reproduction conditions, impact, and the smallest safe evidence
needed to verify the report. Do not open a public issue for an undisclosed
vulnerability or include secrets, user data, or production credentials.

Maintainers will acknowledge the report through GitHub, validate it against a
supported ref, coordinate a fix and disclosure window, and publish verifiable
release information when remediation is available. This repository does not
invent an email security channel and does not collect product telemetry.
