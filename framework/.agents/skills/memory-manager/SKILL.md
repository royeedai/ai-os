# 记忆管理器（vNext）

## 使用时机

- 同类提醒重复出现
- 设计或逻辑决策已经稳定
- 用户偏好已经反复确认
- 事故或回归值得长期记住

## 必做步骤

1. 只记录稳定事实，不记录短期任务
2. 把条目写入 `.ai-os/memory.md`
3. 分类到：
   - 设计决策
   - 逻辑与契约决策
   - 工程约束
   - 用户偏好
   - 已知坑点

## 交付输出

- `.ai-os/memory.md`

## 禁止事项

- 禁止把“今天下一步做什么”写进 memory
- 禁止把未确认猜测写成稳定结论

## 维护信息

- 来源：重复提醒、稳定决策、事故复盘
- 更新时间：2026-03-16
- 已知限制：本 Skill 不记录短期状态
