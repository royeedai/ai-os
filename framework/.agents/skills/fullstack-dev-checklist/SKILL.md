# 全链路开发检查表（vNext）

## 使用时机

- 一个任务同时跨越页面、接口、状态和持久化
- 关键流程需要保证体验、逻辑和工程链路一起成立

## 检查维度

1. 设计一致性：页面结构、信息架构、关键交互是否符合 Design
2. 逻辑正确性：接口契约、状态流转、异常处理是否符合 Spec
3. 工程完整性：测试、错误处理、运行链路、必要配置是否齐全
4. 交付完整性：证据、UAT、回滚和说明是否齐全

## reverse-spec 额外检查

- 关键页面至少有截图或行为对照
- 关键 API 至少有样例或契约对照
- 合理重设计必须被显式记录

## 交付输出

- 设计、逻辑、工程、交付四个维度的检查结果

## 禁止事项

- 禁止只做“看起来能跑”的 demo 式交付

## 维护信息

- 来源：`/build`、`/verify` workflow
- 更新时间：2026-03-16
- 已知限制：只适用于跨层联动任务
