# Spec 校验器（vNext）

## 使用时机

- 生成或更新 spec
- 准备从 `/design` 进入 `/plan`
- 准备从 `/plan` 进入 `/build`

## 校验重点

- 是否能回答“这个模块到底要做什么”
- 是否写清关键流程和状态流转
- 是否写清关键输入、输出、字段和异常路径
- 是否区分了必须先做对的逻辑与允许后补的细节
- 是否写清需要什么证据才能验收

## 交付输出

- 可进入 `/plan` 的 spec
- 或需要补齐的缺口清单

## 禁止事项

- 禁止只有页面描述，没有逻辑规则
- 禁止只有接口字段，没有状态流转
- 禁止 spec 无法支撑验收门

## 维护信息

- 来源：`/design`、`/plan` workflow
- 更新时间：2026-03-16
- 已知限制：本 Skill 只校验 spec，不替代 acceptance
