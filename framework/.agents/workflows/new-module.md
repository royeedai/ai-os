# /new-module（兼容别名）

这是 vNext 的兼容入口。默认不要再把它当成主 workflow 名称。

## 现在应做什么

1. `/align`：确认这个模块的目标、范围和质量标准
2. `/design`：锁定关键页面 / 接口 / 流程
3. `/plan`：生成模块 spec、任务和验收门
4. `/build`：在设计门和逻辑门通过后实现

## 适用

- 新功能模块
- 单模块重构
- 需要正式交付的局部新增
