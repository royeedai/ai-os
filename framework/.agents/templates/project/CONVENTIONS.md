### HTTP 状态码 ↔ 业务码 ↔ 客户端行为映射

> 必须列出本项目可能出现的 HTTP 状态码和业务 code 各自对应的客户端行为，避免拦截器靠"经验"实现。

| HTTP 状态码 | 业务码 | 触发条件 | 客户端行为 |
|------------|-------|---------|----------|
| 401 | （如 40100） | 未登录 / token 过期 | 清 token + 跳登录 + 回填 redirect |
| 403 | （如 40300） | 已登录但无权限 | 弹 Message + 跳登录 / 回首页（明确选择，不要让缺省分支决定） |
| 404 | （如 40400） | 资源不存在 | 弹 Message + 留在原页 |
| 5xx | （如 50000） | 服务器内部错误 | 弹 Message + log + 上报监控 |

### Wire 类型契约

> 必须列出可能跨语言精度损失或多种表达形式的字段类型 wire 格式，并约定后端序列化策略和前端类型声明，避免 Long/UUID/Instant 等字段在某一端被静默截断。

| 字段类型 | 后端表达 | Wire 格式 | 前端类型 | 序列化执行点 |
|---------|---------|----------|---------|------------|
| 主键 ID（如 Snowflake、自增 BIGINT） | （如 Long） | （如 string） | （如 string） | （如全局 Jackson Module，不靠单 DTO 注解） |
| 时间戳 | （如 Instant） | （如 epoch millis number / ISO-8601 string） | （如 string / number） | （如 ObjectMapper / @JsonFormat） |
| Decimal / 金额 | （如 BigDecimal） | （如 string） | （如 string） | （如全局序列化器） |
| 跨边界枚举 | （如 Integer code） | （如 string name） | （如 string） | （如 enum 类双向翻译 + getter @JsonProperty） |

### 名单型常量的反向真理源

> 多租户白名单、CORS、序列化忽略字段集、路由守卫白名单、XSS 转义白名单等所有人工维护的"名单型常量"，必须在此声明其反向来源（"此列表必须等于 X 的什么子集"）。

| 名单常量位置 | 反向来源 | 同步触发时机 | 一致性校验位置 |
|------------|---------|------------|--------------|
| （如 `TenantInterceptor.IGNORE_TABLES`） | （如 schema.sql 中不含 tenant_id 列的业务表全集） | （新增表 / 新增字段时同步） | （如启动期反射扫描 + 测试断言） |
| （如 `CorsConfig.ALLOWED_ORIGINS`） | （如部署文档中明确列出的对外域名） | （新增环境时同步） | （如启动期 log + 部署 checklist） |

### 敏感数据 service 方法语义档位

> 同一 Entity 的 service 方法因加密/解密/打码语义不同必须有不同命名档位，跨模块消费者必须知道用哪一档；命名档位约定如下。

| 方法档位 | 命名后缀约定 | 返回字段语义 | 跨模块默认是否可用 |
|--------|------------|-----------|----------------|
| 对外展示版 | （如 `getXxxForDisplay` / `getXxxPublicView`） | 敏感字段打码 / 置 null | 仅展示；建链接 / 解密类下游消费禁止使用 |
| 原始版 | （如 `getXxxRaw` / `getXxxDecrypted`） | 字段真实可用 | 内部模块允许；不得外泄到对外接口 |

### 中间件 / 查询引擎方言契约

> 凡是承担 SQL / DSL 拼装的中间层组件（Calcite、MyBatis 自定义方言、ES DSL Builder、Redis Pipeline 等），其方言假设必须显式登记，调用方必须按同一方言拼接，禁止凭直觉选择。

| 组件 / 引擎 | 方言假设 | 标识符引号 | 是否允许末尾 `;` | 保留字大小写 | 调用方约束 |
|------------|--------|-----------|---------------|------------|----------|
| （如 `CalciteQueryEngine`） | （如 `lex=MYSQL`） | （如反引号 `` ` ``） | （如否；嵌入子查询前必须 strip） | （如不敏感） | （如所有 `quoteIdentifier` 必须用反引号） |
| （如 MyBatis 自定义 SQL） | （如 H2 兼容模式） | （如双引号） | （如允许） | （如敏感） | （如保留字必须显式加引号） |
